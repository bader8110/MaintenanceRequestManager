# Changelog

## Version 3.0 - Workflow and management update

- Added request editing with automatic update timestamps.
- Added request deletion with a confirmation prompt.
- Added role rules: administrators manage every request; regular users can edit or delete only their own requests while they are new.
- Added dashboard filters for priority and category, alongside search and status filtering.
- Improved dashboard toolbar layout and kept CSV export, statistics, notes, language settings, and theme settings.

## Version 2.0

- Added complete English and Arabic interface support.
- Added light and dark appearance modes.
- Added a settings window with saved preferences.
- Added optional confirmation before logout.
- Added a Logout button for fast account switching.
- Added Refresh and Clear dashboard actions.
- Added color-coded request status and priority values.
- Added localized validation, success, export, and confirmation messages.
- Updated the project report and student guide for the new features.

## Version 1.0

- Initial maintenance request workflow.
- User and administrator roles.
- Search, status filtering, JSON persistence, and CSV export.
